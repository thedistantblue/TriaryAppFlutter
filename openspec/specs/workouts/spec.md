# Workouts Specification

## Purpose

Тренировки с датой, ссылающиеся на набор упражнений, со списком, сгруппированным по датам, созданием и удалением.

## Requirements

### Requirement: Создание тренировки
Пользователь ДОЛЖЕН иметь возможность создать тренировку с названием, описанием и выбранным (или созданным) набором упражнений.

#### Scenario: Создание тренировки с выбором набора
- **WHEN** пользователь создаёт тренировку, указывает название и выбирает набор упражнений
- **THEN** тренировка создаётся и появляется в списке

#### Scenario: Создание набора в процессе создания тренировки
- **WHEN** при создании тренировки нет подходящего набора и пользователь создаёт новый
- **THEN** новый набор создаётся и привязывается к тренировке

### Requirement: Список тренировок
Система ДОЛЖНА показывать список тренировок, сгруппированный по периодам дат (например, по месяцам).

#### Scenario: Группировка по месяцам
- **WHEN** пользователь открывает список тренировок
- **THEN** тренировки группируются по месяцам их дат

### Requirement: Выбор группировки и сортировки
Пользователь ДОЛЖЕН иметь возможность выбирать вариант группировки и сортировки списка тренировок.

#### Scenario: Смена варианта сортировки
- **WHEN** пользователь выбирает другой вариант группировки или сортировки
- **THEN** список тренировок перестраивается согласно выбору

### Requirement: Удаление тренировки
Пользователь ДОЛЖЕН иметь возможность удалить тренировку с подтверждением.

#### Scenario: Удаление тренировки
- **WHEN** пользователь удаляет тренировку и подтверждает
- **THEN** тренировка удаляется из хранилища и исчезает из списка

### Requirement: Сохранение даты завершения
Система ДОЛЖНА сохранять текущую дату в тренировку в момент нажатия кнопки завершения тренировки.

#### Scenario: Фиксация даты при завершении
- **WHEN** пользователь завершает тренировку
- **THEN** в тренировку записывается сегодняшняя дата

### Requirement: Просмотр деталей тренировки
Пользователь ДОЛЖЕН иметь возможность открыть тренировку, чтобы просмотреть её детали и перейти к выполнению или статистике.

#### Scenario: Открытие тренировки
- **WHEN** пользователь открывает тренировку из списка
- **THEN** отображаются детали тренировки с доступом к выполнению и статистике
