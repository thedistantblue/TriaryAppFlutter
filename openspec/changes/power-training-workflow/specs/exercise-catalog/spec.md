# Spec Delta

## Purpose

Справочник упражнений силовых тренировок: упражнения, сгруппированные по категориям мышц с поддержкой подкатегорий.

## ADDED Requirements

### Requirement: Просмотр категорий
Система ДОЛЖНА показывать список категорий верхнего уровня, у каждой из которых видно количество содержащихся в ней упражнений.

#### Scenario: Отображение категории со счётчиком
- **WHEN** пользователь открывает вкладку «Упражнения»
- **THEN** отображается список категорий, у каждой — количество упражнений в ней

### Requirement: Переход к подкатегориям
Категория МОЖЕТ содержать подкатегории. Пользователь ДОЛЖЕН иметь возможность открыть категорию и увидеть её подкатегории с количеством упражнений; если подкатегорий нет — сразу список упражнений.

#### Scenario: Категория с подкатегориями
- **WHEN** пользователь открывает категорию, у которой есть подкатегории
- **THEN** отображается список подкатегорий с количеством упражнений в каждой

#### Scenario: Категория без подкатегорий
- **WHEN** пользователь открывает категорию без подкатегорий
- **THEN** отображается список упражнений этой категории

### Requirement: Просмотр упражнений
Система ДОЛЖНА показывать список упражнений выбранной категории или подкатегории.

#### Scenario: Список упражнений
- **WHEN** пользователь открывает категорию или подкатегорию, содержащую упражнения
- **THEN** отображается список упражнений этой категории

### Requirement: Добавление категории и подкатегории
Пользователь ДОЛЖЕН иметь возможность добавить категорию или подкатегорию. Название обязательно и уникально.

#### Scenario: Успешное добавление
- **WHEN** пользователь вводит уникальное непустое название и подтверждает
- **THEN** категория (или подкатегория) создаётся и появляется в списке

#### Scenario: Пустое название
- **WHEN** пользователь подтверждает с пустым названием
- **THEN** создание отклоняется

#### Scenario: Дубликат названия
- **WHEN** пользователь вводит название, которое уже существует
- **THEN** создание отклоняется

### Requirement: Добавление упражнения
Пользователь ДОЛЖЕН иметь возможность добавить упражнение в выбранную категорию или подкатегорию.

#### Scenario: Добавление упражнения
- **WHEN** пользователь добавляет упражнение в категорию
- **THEN** упражнение создаётся и появляется в списке категории

### Requirement: Удаление элемента справочника
Пользователь ДОЛЖЕН иметь возможность удалить категорию, подкатегорию или упражнение; удаление должно сопровождаться подтверждением и удалять элемент из хранилища.

#### Scenario: Удаление упражнения
- **WHEN** пользователь удаляет упражнение и подтверждает
- **THEN** упражнение удаляется из хранилища и исчезает из списка
