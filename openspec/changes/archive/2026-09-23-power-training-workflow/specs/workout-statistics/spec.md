# Spec Delta

## Purpose

Итоговая статистика завершённой тренировки и участие упражнений, удалённых из набора, в статистике старых тренировок.

## ADDED Requirements

### Requirement: Просмотр итогов тренировки
Система ДОЛЖНА показывать итог завершённой тренировки: дату, количество выполненных упражнений, использованный набор и список упражнений.

#### Scenario: Отображение итогов
- **WHEN** пользователь открывает статистику завершённой тренировки
- **THEN** отображаются дата, количество выполненных упражнений, название набора и список упражнений

### Requirement: Отображение удалённых из набора упражнений
Упражнения, удалённые из набора уже после тренировки, ДОЛЖНЫ продолжать отображаться в статистике этой тренировки с визуальной пометкой (например, серым цветом).

#### Scenario: Пометка удалённого упражнения в статистике
- **WHEN** пользователь открывает статистику тренировки, из чьего набора позже было удалено упражнение
- **THEN** удалённое упражнение остаётся в статистике с пометкой удалённого
