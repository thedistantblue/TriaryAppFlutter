# Spec Delta

## Purpose

Именованные наборы упражнений, которые можно переиспользовать в тренировках, с выбором текущего набора и защитой используемых наборов.

## ADDED Requirements

### Requirement: Создание набора
Пользователь ДОЛЖЕН иметь возможность создать набор упражнений с названием и опциональным описанием. Название обязательно и уникально.

#### Scenario: Создание набора
- **WHEN** пользователь вводит уникальное название и подтверждает
- **THEN** набор создаётся и появляется в списке наборов

#### Scenario: Дубликат названия набора
- **WHEN** пользователь вводит название, которое уже есть у другого набора
- **THEN** создание отклоняется

### Requirement: Просмотр наборов
Система ДОЛЖНА показывать список наборов упражнений с количеством упражнений в каждом.

#### Scenario: Список наборов
- **WHEN** пользователь открывает список наборов
- **THEN** отображаются наборы, у каждого — количество упражнений

### Requirement: Выбор текущего набора
Первый созданный набор автоматически становится текущим. Пользователь ДОЛЖЕН иметь возможность выбрать другой набор как текущий.

#### Scenario: Автовыбор первого набора
- **WHEN** пользователь создаёт первый набор
- **THEN** этот набор помечается как текущий

#### Scenario: Смена текущего набора
- **WHEN** пользователь выбирает другой набор как текущий
- **THEN** выбранный набор помечается как текущий, прежний теряет этот статус

### Requirement: Изменение состава и порядка набора
Пользователь ДОЛЖЕН иметь возможность добавлять упражнения в набор, удалять их из набора и менять их порядок.

#### Scenario: Изменение порядка упражнений
- **WHEN** пользователь переставляет упражнения внутри набора
- **THEN** новый порядок сохраняется

#### Scenario: Добавление упражнения в набор
- **WHEN** пользователь добавляет упражнение в набор
- **THEN** упражнение появляется в наборе

### Requirement: Мягкое удаление упражнения из набора
Упражнение, удалённое из набора, который используется в прошлых тренировках, ДОЛЖНО помечаться как удалённое: оно не показывается в новых тренировках, но продолжает отображаться в статистике старых тренировок (например, серым цветом).

#### Scenario: Удаление упражнения из используемого набора
- **WHEN** пользователь удаляет упражнение из набора, задействованного хотя бы в одной тренировке
- **THEN** упражнение помечается удалённым, не показывается при создании новых тренировок, но остаётся видимым в статистике старых тренировок

### Requirement: Защита набора от удаления
Набор, задействованный хотя бы в одной тренировке, ДОЛЖЕН быть защищён от удаления.

#### Scenario: Попытка удалить используемый набор
- **WHEN** пользователь пытается удалить набор, используемый в тренировках
- **THEN** удаление отклоняется

### Requirement: Удаление неиспользуемого набора
Набор, не задействованный ни в одной тренировке, ДОЛЖЕН удаляться с подтверждением.

#### Scenario: Удаление неиспользуемого набора
- **WHEN** пользователь удаляет набор, не используемый в тренировках, и подтверждает
- **THEN** набор удаляется из хранилища
