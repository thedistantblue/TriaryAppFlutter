# Proposal

## Why

Сейчас приложение умеет хранить только «плоскую» силовую тренировку (PowerTraining: id, name, description) и показывать её простым списком. Набросок в `TriaryApp.excalidraw` описывает полноценный сценарий силовой тренировки, ради которого приложение и задумано: справочник упражнений по группам мышц, переиспользуемые наборы упражнений, тренировки с датой, фиксация подходов (повторы/вес) с таймером отдыха, история по каждому упражнению с «применением прошлых значений» и итоговая статистика. Этот чейндж превращает заглушки UI в этот сценарий.

## What Changes

- Новые доменные сущности: категория упражнений (двухуровневая), упражнение, набор упражнений (упорядоченный), тренировка (расширенная PowerTraining), подход тренировки (повторы + вес).
- Новые экраны: справочник упражнений (категории → подкатегории → упражнения), управление наборами, список тренировок (группировка/сортировка по дате), выполнение тренировки (подходы, таймер, история), статистика.
- Новые бизнес-правила: обязательные и уникальные названия, автовыбор текущего набора, мягкое удаление упражнений из набора и защита используемых наборов от удаления, цветовая индикация применённых прошлых значений.
- Расширение слоя хранения (drift) и bloc-слоя.
- Сущность PowerTraining расширяется полями даты и ссылкой на набор упражнений; схема drift мигрирует (schemaVersion 2 → 3).
- Кардио-тренировки остаются заглушкой (вне скоупа, отдельный будущий чейндж).

## Capabilities

### New Capabilities
- `exercise-catalog`: категории с подкатегориями и упражнения; просмотр, счётчики, добавление/удаление, уникальные названия.
- `exercise-sets`: именованные упорядоченные наборы упражнений; создание/выбор/изменение порядка; мягкое удаление и защита используемых.
- `workouts`: тренировки с датой, ссылающиеся на набор упражнений; список с группировкой/сортировкой, создание, удаление.
- `workout-execution`: выполнение тренировки — подходы по упражнению (повторы/вес), добавление/удаление, таймер отдыха, применение прошлых записей, завершение с подтверждением.
- `workout-statistics`: итог завершённой тренировки (дата, выполнено упражнений, набор, список упражнений).

### Modified Capabilities

(нет — в проекте ещё нет спецификаций.)

## Impact

- `packages/entity`: новые сущности + JSON-сериализация; PowerTraining расширяется (date + ссылка на набор).
- `packages/storage_api`: расширение интерфейсов репозиториев (категории, упражнения, наборы, тренировки, подходы).
- `packages/storage_local_api`: новые таблицы drift + миграция; реализации репозиториев.
- `packages/storage_mock_api`: соответствующие mock-реализации.
- `lib`: новые экраны, bloc, маршруты, строки локализации (ru/en).
- Новых сторонних зависимостей не ожидается (таймер — встроенный Timer, порядок — ReorderableListView, группировка — существующая работа с датами).
