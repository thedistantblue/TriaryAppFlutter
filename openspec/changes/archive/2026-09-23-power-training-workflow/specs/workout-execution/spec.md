# Spec Delta

## Purpose

Выполнение тренировки: фиксация подходов по упражнениям (повторы и вес), таймер, применение прошлых записей и завершение тренировки.

## ADDED Requirements

### Requirement: Отображение упражнений с подходами
Система ДОЛЖНА показывать упражнения выполняемой тренировки с их подходами (повторы и вес).

#### Scenario: Показ упражнений и подходов
- **WHEN** пользователь выполняет тренировку
- **THEN** отображается список упражнений, у каждого — его подходы с повторами и весом

### Requirement: Добавление подхода
Пользователь ДОЛЖЕН иметь возможность добавить подход к упражнению. Каждое добавление сразу сохраняется в хранилище.

#### Scenario: Добавление подхода
- **WHEN** пользователь добавляет подход с повторами и весом
- **THEN** подход сохраняется в хранилище и отображается у упражнения

### Requirement: Удаление подхода
Пользователь ДОЛЖЕН иметь возможность удалить подход с подтверждением; удаление удаляет подход из хранилища.

#### Scenario: Удаление подхода
- **WHEN** пользователь удаляет подход и подтверждает
- **THEN** подход удаляется из хранилища и исчезает из списка

### Requirement: Начало и завершение упражнения с таймером
Система ДОЛЖНА отслеживать время выполнения упражнения и время отдыха между подходами, показывая таймер.

#### Scenario: Отслеживание времени выполнения
- **WHEN** пользователь начинает упражнение
- **THEN** система фиксирует время выполнения упражнения

#### Scenario: Таймер отдыха
- **WHEN** пользователь завершает подход и переходит к отдыху
- **THEN** система показывает таймер отдыха

### Requirement: Переход между упражнениями
Пользователь ДОЛЖЕН иметь возможность перейти к следующему упражнению тренировки.

#### Scenario: Переход к следующему упражнению
- **WHEN** пользователь нажимает «Следующее упражнение»
- **THEN** выполнение переходит к следующему упражнению тренировки

### Requirement: Завершение тренировки
Пользователь ДОЛЖЕН иметь возможность завершить тренировку; перед завершением система запрашивает подтверждение.

#### Scenario: Завершение с подтверждением
- **WHEN** пользователь нажимает «Завершить тренировку»
- **THEN** показывается подтверждение, и после согласия тренировка завершается

### Requirement: Предыдущие записи по упражнению
Система ДОЛЖНА показывать историю прошлых подходов по упражнению. Пользователь ДОЛЖЕН иметь возможность выбирать, показывать записи по всем тренировкам или только по текущей.

#### Scenario: Просмотр истории по всем тренировкам
- **WHEN** пользователь открывает предыдущие записи упражнения с выбором «все тренировки»
- **THEN** показываются прошлые подходы упражнения из всех тренировок

#### Scenario: Просмотр истории только текущей тренировки
- **WHEN** пользователь ограничивает записи текущей тренировкой
- **THEN** показываются подходы упражнения только из текущей тренировки

### Requirement: Применение прошлых значений
Пользователь ДОЛЖЕН иметь возможность применить значения из прошлой тренировки к текущему упражнению. Применённые значения и добавленные вручную должны визуально различаться.

#### Scenario: Применение прошлых значений
- **WHEN** пользователь применяет значения из прошлой тренировки
- **THEN** подходы переносятся в текущее упражнение

#### Scenario: Цветовое различие записей
- **WHEN** часть подходов применена из прошлой тренировки, а часть добавлена вручную
- **THEN** применённые подходы отображаются одним цветом, добавленные вручную — другим
